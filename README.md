# Kapten-hwacha Tap

## How do I install these formulae?

`brew install kapten-hwacha/tap/<formula>`

Or `brew tap kapten-hwacha/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kapten-hwacha/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
